# Competition Rules & Boundaries

1. **Tournament Constraints**:
   - Total match duration: 40 minutes.
   - Max 1,000 points total available across the backlog.
   - Points breakdown:
     - PI (Production Incident): 250 points (latency penalty applies: faster submission scores higher).
     - CR (Change Request): 300 points.
     - BUG: 200 points.
     - TASK (Refactor/Chore): 150 points.

2. **Once-Only Submission**:
   - A task can only be submitted once to the Game Master.
   - An unsuccessful submission burns the points permanently.
   - Every submission MUST be fully verified before submission.

3. **Workspace Isolation**:
   - Each worker operates within its own isolated worktree or directory.
   - Cross-task file tampering will result in submission disqualification.
