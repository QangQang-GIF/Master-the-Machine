The COBOL programs are not modified. Everything needed to run them under
GnuCOBOL is outside the programs:

| file | replaces |
|---|---|
| `jobs/posttran.sh`, `jobs/intcalc.sh`, `jobs/tranrept.sh` | JCL `POSTTRAN`, `INTCALC`, `TRANREPT` (the TRANREPT DFSORT step = awk filter on TRAN-PROC-TS + stable sort on TRAN-CARD-NUM) |
| `jobs/lib.sh` | DD statements (`DD_<name>` env vars), RECFM=F <-> text conversion |
| `tools/KSDS*.cbl` | IDCAMS REPRO into/out of the VSAM KSDS (GnuCOBOL BDB indexed files) |
| `tools/PARMRUN.cbl` | `EXEC PGM=CBACT04C,PARM='...'` (builds the half-word length + text parameter) |
| `tools/CEE3ABD.cbl` | LE abend service (prints code, RC=16) |
| `build.sh` | compile JCL; `-fsign=EBCDIC` so the overpunched zoned decimals of the ASCII data files are read as on z/OS |

Written for this suite (not upstream): the files in the table above,
`README.md`, `tests/run_case.sh`, `tests/run_all.sh`, `gen_cases.py` and the
generated `cases/`. Known upstream quirks are kept as reference behaviour
(e.g. CBACT04C never rewrites the last account of the run; CBTRN03C adds the
last amount once more at end of file and writes no account total for the last
card).

## Test data

`cases/` is generated by `gen_cases.py` (deterministic): the shipped sample
data, hand-built edge cases (`posttran_edge`) and seeded random variations.
`expected/` is produced by `build.py --regen` from the reference programs.
